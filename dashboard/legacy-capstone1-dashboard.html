How ingestion works
1
Parse & detect format
System reads the file and identifies CycloneDX 1.4, SPDX 2.3, or raw package manifest (package.json, requirements.txt)
2
SBOM quality gate
Every component must have a PURL or CPE identifier. Components missing both are flagged — we don't silently skip them
3
PURL correlation engine
Each component PURL is matched against the CVE database using semantic version range evaluation. Falls back to CPE fuzzy matching if PURL is absent
4
Transitive traversal
Dependency graph is built with NetworkX. Even if you don't directly use a vulnerable package, the system traces it through indirect dependencies
5
Composite risk score
Score = (CVSS × 0.5) + (EPSS × 0.3) + (Criticality × 0.2) — combines technical severity, real exploitation probability, and business impact
